# Локальные проверки Git

В CheenHub используется [Lefthook](https://lefthook.dev/installation/) — одна
конфигурация `lefthook.yml` для Linux, Windows и macOS.

## Установка в каждом клоне репозитория

1. Установите Lefthook для своей ОС и проверьте командой `lefthook version`.
2. Убедитесь, что доступны `cargo`, `rustfmt` и `clippy` из `rust-toolchain.toml`.
3. Для измерения покрытия установите инструменты:

   ```text
   rustup component add llvm-tools-preview
   cargo install cargo-llvm-cov --locked
   ```

4. Из корня репозитория выполните:

   ```text
   lefthook install
   lefthook validate
   ```

На Windows используйте стандартную сборку Rust с целевым окружением MSVC:
измерение покрытия на `x86_64-pc-windows-gnu` по умолчанию не поддерживается.

## Когда запускаются проверки

- `git commit`: `cargo fmt --all -- --check`, Clippy с `-D warnings`, затем
  `cargo test --workspace --all-targets`.
- `git push`: тесты под инструментированным `cargo llvm-cov`, затем сравнение
  общего покрытия строк с сохранённым эталоном для текущей ОС.

Коммит или push отклоняется, если соответствующая команда завершилась ошибкой.
Проверки запускаются на текущем **рабочем дереве**, включая неиндексированные
изменения, а не на отдельном снимке staged-файлов.

## Первичная запись эталона покрытия

В `coverage/baselines.json` уже сохранён измеренный эталон для Linux.
Для каждой другой ОС нужен собственный результат: покрытие нельзя переносить
между платформами. До первого push с новой ОС выполните:

```text
cargo run -p xtask -- coverage-gate record
git add coverage/baselines.json
git commit -m "test(coverage): record local coverage baseline"
```

На Windows запишите собственный эталон и закоммитьте дополнение
того же файла. В существующем эталоне команда `record` разрешает только
равное или более высокое покрытие. Результат измеряется по паре целых чисел
`covered/count`, а не по округлённым процентам.

Для ручного запуска проверки используйте:

```text
cargo run -p xtask -- coverage-gate check
```

Если покрытие снизилось, добавьте тесты или верните непокрытый код к
покрытому состоянию. Снижение сохранённого эталона не выполняется
автоматически. Отчёт измерения находится в
`target/llvm-cov/cheenhub-summary.json` и не попадает в Git.

Локальные hooks устанавливаются отдельно в каждом клоне и могут быть
обойдены командой `git commit --no-verify` или `git push --no-verify`.
Обязательный запрет на стороне GitHub требует отдельной CI-проверки и
защиты ветки. Существующие проверки релизного тега не меняются.
