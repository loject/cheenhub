# CheenHub

**Голосовая связь для игр — быстро, просто и на своих условиях.**

Зови друзей в голосовую комнату, общайся во время игры, делись экраном и переписывайся. CheenHub работает прямо в браузере, а если хочется — в отдельном приложении. И да, можно развернуть собственный сервер.

**[Начать общение →](https://cheenhub.ru/app)** · [Скачать приложение](https://cheenhub.ru/) · [Посмотреть возможности](https://cheenhub.ru/#features)

## Почему CheenHub?

- **Голос с низкой задержкой.** WebTransport и кодек Opus помогают передавать звук без лишних промежуточных шагов. На собственном сервере в локальной сети задержка может быть особенно низкой — результат зависит от сети и устройства.
- **Твоя компания — твои правила.** Создавай комнаты, приглашай друзей и общайся на своём сервере. Для LAN можно разместить сервер прямо в локальной сети.
- **Не нужно ничего устанавливать, чтобы попробовать.** Открой веб-приложение и заходи в разговор. Для привычного рабочего стола есть отдельные клиенты.
- **Голос, переписка и демонстрация экрана.** Всё нужное для игры и общения в одном месте.
- **Открытый код без рекламного трекинга.** Можно посмотреть, как работает проект, предложить улучшение или запустить собственную копию. Код доступен под лицензией MIT.

## Начать за минуту

1. **[Открой CheenHub](https://cheenhub.ru/app)** в браузере.
2. Войди или зарегистрируйся, создай сервер или присоединись к друзьям по приглашению.
3. Зайди в голосовую комнату и общайся. При желании используй текстовый чат или демонстрацию экрана.

**Предпочитаешь приложение?** На [сайте CheenHub](https://cheenhub.ru/) доступны загрузки для Windows, Ubuntu и Android. Можно также установить веб-приложение как PWA.

## Хочешь собственный сервер?

CheenHub поддерживает самостоятельное размещение. Ты выбираешь, где работает сервер: у себя дома, в локальной сети или на арендованной машине.

Для Linux x86_64 готовится установщик с загрузкой и обновлением одной командой:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/loject/cheenhub/main/install.sh)
```

Подробности для самостоятельного развёртывания — в [инструкции по установке и настройке](deploy/README.md).

## Вопросы, которые могут возникнуть

**Нужно ли поднимать свой сервер, чтобы общаться?** Нет. Для начала достаточно [открыть CheenHub](https://cheenhub.ru/app).

**CheenHub бесплатный?** Абсолютно! Проект распространяется с открытым исходным кодом под лицензией MIT. Браузерный клиент доступен бесплатно.

**Можно ли использовать его для LAN?** Да. На собственной машине или в локальной сети можно разместить сервер для общения между участниками этой сети. Для полноценного развёртывания потребуется настройка сервера.
